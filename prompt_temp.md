3) самый простой и лёгкий вариант для пользователя, но сложный вариант для программирования: предлагать на каждом шаге несколько букв, которые могут быть на первом месте (можно выбирать через soundex(), можно предлагать кроме правильной буквы гласной, также следующую согласную, можно предлагать буквы, которые дают похожие по звучанию звуки).

Аналогично - подбор слов близких по звучанию с помощью команд или алгоритмов близких к функции soundex().
